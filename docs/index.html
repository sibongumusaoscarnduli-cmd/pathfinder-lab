01 / THE MODEL

Cost is not distance.

Each move pays the cost of entering the next cell. A longer path around rough terrain can be cheaper. The starting cell costs zero.

02 / THE HEURISTIC

An informed search.

A* estimates remaining cost using Manhattan distance × minimum terrain cost. On this four-way grid, that estimate never overstates the true cost.

03 / THE EVIDENCE

Same optimum. Different work.

Compare settled cells, not just path length. Tie-breaking and obstacles affect exploration; A* does not promise fewer expansions on every map.
